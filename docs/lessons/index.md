# Technical Contributor Program
### Lessons

Each of the lessons below discusses a topic or skill that you will need to be(come) a TEI Technical Contributor. The lessons are set up in such a way, that you slowly work your way through every aspect of the TEI. You may already be familiar with certain subjects; in that case you're welcome to skim the lesson(s). For example, if you know your way around [Pull Requests on GitHub]({% link lessons/lesson-10.md %}) in general, you will only need to know the TEI Council's particular customs around PRs.
