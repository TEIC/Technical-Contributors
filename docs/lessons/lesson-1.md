#### Lesson 1: Introduction to the TEI Guidelines
In this lesson, you learn how the TEI Guidelines are organised. The TEI encoding scheme consists of a number of modules, each of which declares particular XML *elements* and their *attributes*. Part of an element's declaration includes its assignment to one or more *element classes*. Another part defines its possible content and attributes with reference to these classes. The *datatypes* constrain the range of legal values for TEI attributes. Finally, *macros* are used to express some commonly used content models.

You'll find detailed information about this system in the [first chapter](https://www.tei-c.org/release/doc/tei-p5-doc/en/html/ST.html) of the TEI Guidelines. The references below link to overviews of modules, attribute classes, element classes, macros, and datatypes:

    * [Attributes](https://tei-c.org/release/doc/tei-p5-doc/en/html/REF-ATTS.html)
    * [Attribute Classes](https://tei-c.org/release/doc/tei-p5-doc/en/html/REF-CLASSES-ATTS.html)
    * [Model Classes](https://tei-c.org/release/doc/tei-p5-doc/en/html/REF-CLASSES-MODEL.html)
